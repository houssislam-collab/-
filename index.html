مقدمة

لغة HTML (HyperText Markup Language) هي لغة التوصيف القياسية المستخدمة في إنشاء صفحات الويب. تُعدّ اللبنة الأساسية التي تقوم عليها شبكة الإنترنت، وهي وسيلة التواصل الأولى بين المتصفحات وخوادم الويب.


ظهرت HTML لأول مرة عام 1991 على يد العالم البريطاني تيم بيرنرز-لي، وتطورت عبر إصدارات متعددة حتى وصلنا إلى الإصدار الحالي HTML5 الذي أضاف ميزات قوية تدعم الوسائط والرسوميات والعناصر الدلالية.

💡 HTML وحدها لا تكفي — تُكمّلها CSS للتصميم وJavaScript للتفاعل، وتُشكّل معاً ثلاثية تطوير الواجهة الأمامية (Front-End).
٢
الهيكل الأساسي لصفحة HTML

تتكون كل صفحة ويب من هيكل أساسي موحّد يُعرف بـ "الهيكل العظمي" للصفحة:

HTML 
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8">
    <title>عنوان الصفحة</title>
  </head>
  <body>
    <!-- المحتوى المرئي هنا -->
  </body>
</html>
٣
المكونات الرئيسية
📌 إعلان نوع المستند <!DOCTYPE html>

يُخبر المتصفح بأن الصفحة مكتوبة بلغة HTML5. يجب أن يكون دائماً السطر الأول، وهو تعليمة للمتصفح وليس وسماً.

🌐 العنصر الجذري <html>

يحتوي على جميع عناصر الصفحة. يُحدّد اللغة (lang) واتجاه الكتابة (dir).

🧠 رأس الصفحة <head>

يحتوي على المعلومات الوصفية التي لا تظهر للمستخدم مباشرةً:

العنصرالوظيفة
<title>عنوان الصفحة في شريط المتصفح
<meta charset>ترميز الأحرف المستخدم (UTF-8)
<meta name>الوصف والكلمات المفتاحية لمحركات البحث
<link>ربط ملفات CSS الخارجية
<style>إضافة أنماط CSS داخل الصفحة
<script>إضافة أو ربط ملفات JavaScript
👁️ جسم الصفحة <body>

يحتوي على كل المحتوى المرئي للمستخدم من نصوص وصور وجداول وروابط.

٤
عناصر المحتوى داخل <body>
أ. العناوين (Headings)

توفر HTML ستة مستويات من العناوين من h1 (الأكبر) إلى h6 (الأصغر):

HTML
<h1>العنوان الرئيسي — الأكبر</h1>
<h2>العنوان الثاني</h2>
<h3>العنوان الثالث</h3>
<!-- وهكذا حتى <h6> -->
ب. عناصر النص
  • <p>  — لإنشاء فقرات نصية مستقلة
  • <strong>  — نص عريض Bold مع دلالة أهمية
  • <em>  — نص مائل Italic مع دلالة تأكيد
  • <span>  — تنسيق أجزاء صغيرة من النص
  • <br>  — سطر جديد داخل الفقرة
  • <hr>  — خط أفقي فاصل
ج. الروابط <a>

الروابط تُربط صفحات الويب ببعضها وهي جوهر الإنترنت:

HTML
<a href="https://www.example.com" target="_blank">
  اضغط هنا لزيارة الموقع
</a>
د. الصور <img>
HTML
<img src="صورة.jpg" alt="وصف الصورة"
     width="300" height="200">
  • src — مسار ملف الصورة
  • alt — النص البديل عند تعذّر التحميل
  • width / height — أبعاد الصورة بالبيكسل
هـ. القوائم
HTML
<!-- قائمة غير مرتبة -->
<ul>
  <li>العنصر الأول</li>
  <li>العنصر الثاني</li>
</ul>

<!-- قائمة مرتبة بأرقام -->
<ol>
  <li>الخطوة الأولى</li>
  <li>الخطوة الثانية</li>
</ol>
و. الجداول <table>
HTML
<table>
  <thead>
    <tr>
      <th>العمود 1</th>
      <th>العمود 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>بيانات</td>
      <td>بيانات</td>
    </tr>
  </tbody>
</table>
ز. النماذج <form>
HTML
<form action="/submit" method="post">
  <label for="name">الاسم:</label>
  <input type="text" id="name">
  <input type="email" placeholder="البريد الإلكتروني">
  <input type="submit" value="إرسال">
</form>
٥
العناصر الهيكلية في HTML5

أضاف HTML5 عناصر دلالية (Semantic Elements) تُنظّم هيكل الصفحة وتُحسّن وصول محركات البحث وقارئات الشاشة:

العنصرالوظيفة والموقع في الصفحة
<header>رأس الصفحة — الشعار والقائمة الرئيسية
<nav>قسم التنقل والروابط الرئيسية
<main>المحتوى الرئيسي — يكون واحداً فقط
<article>محتوى مستقل كمقال أو خبر
<section>قسم موضوعي له عنوان خاص
<aside>محتوى جانبي مكمّل كالملاحظات
<footer>تذييل الصفحة — حقوق النشر والتواصل
<div>حاوية عامة غير دلالية للتنسيق
٦
الخصائص (Attributes)

الخصائص معلومات إضافية تُضاف داخل الوسم الافتتاحي لتحديد سلوكه أو شكله:

HTML
<وسم خاصية1="قيمة1" خاصية2="قيمة2"> المحتوى </وسم>
الخاصيةالوظيفة
idمعرّف فريد لكل عنصر في الصفحة
classفئة لتطبيق أنماط CSS على مجموعة عناصر
styleتنسيق مباشر (Inline CSS)
titleنص يظهر عند تمرير الفأرة
dirاتجاه النص: rtl أو ltr
hiddenإخفاء العنصر عن الشاشة

مثال صفحة ويب متكاملة

مثال كامل يجمع أبرز العناصر التي تعلمناها:

HTML — مثال كامل
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>مدرستي الجميلة</title>
</head>
<body>
  <header>
    <h1>موقع مدرستي</h1>
    <nav>
      <a href="#">الرئيسية</a>
      <a href="#">تواصل معنا</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>عن المدرسة</h2>
      <p>مدرسة متميزة تضم أفضل الطلاب.</p>
      <img src="school.jpg" alt="صورة المدرسة">
    </section>
  </main>
  <footer>
    <p>جميع الحقوق محفوظة 2025</p>
  </footer>
</body>
</html>
٨
الخلاصة
  • كل صفحة HTML تبدأ بـ <!DOCTYPE html> وتحتوي على العنصر الجذري <html>
  • يُقسم الهيكل إلى <head> للمعلومات الوصفية و<body> للمحتوى المرئي
  • عناصر HTML متداخلة (Nested) ولكل منها دور دلالي محدد
  • HTML5 أضاف عناصر دلالية تُحسّن تجربة المستخدم ومحركات البحث
  • الخصائص تُغني العناصر بمعلومات تتحكم في سلوكها وشكلها
🚀 الخطوة التالية: تعلّم CSS لإضافة الألوان والتصميم، ثم JavaScript لإضافة الحركة والتفاعل!
